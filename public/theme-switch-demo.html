覆盖层效果 — 通过 -rgb 伴侣变量实现
核心用法：rgba(var(--brand-color-rgb), 0.72) — 纯 CSS 实现，无需 JavaScript 运行时转换。TokenHelper 在 setBaseColor() 时自动为每个 hex 变量生成对应的 -rgb 伴侣变量（纯数值格式如 255, 107, 53），直接嵌入 rgba() 函数中使用。
格式: rgba(var(--xxx-rgb), <alpha>)
当前: rgba(var(--brand-color-rgb), 0.72)
